# NEIROmaster 5.0

Система работы с нейросетями для digital-специалистов. Премиум лендинг для курса по ИИ с высокотехнологичным дизайном.

## 🎯 Описание

NEIROmaster 5.0 — это полнофункциональный лендинг курса, разработанный с использованием современных технологий и премиум дизайна. Сайт демонстрирует систему работы с нейросетями и предлагает три уровня обучения.

## ✨ Ключевые особенности

- **4-слойная архитектура фона**: Анимированная нейросеть, размытые неоновые сферы, стеклянные панели, неоновая типография
- **Премиум дизайн**: Электрический синий (#3B82F6), голубой (#22D3EE) и фиолетовый (#8B5CF6) неоновые акценты
- **Полная анимация**: Плавные переходы, hover-эффекты, параллакс-эффекты
- **Мобильная оптимизация**: Mobile-first подход, адаптивный дизайн
- **Интерактивные элементы**: Аккордеоны, карточки, стеклянные панели

## 📋 Содержание

### 12 основных блоков:

1. **Hero** — Заголовок, подзаголовок, две кнопки с неоновым свечением
2. **Почему ИИ не работает** — 2-колонка с анимированной диаграммой
3. **Кому подойдёт** — Аккордеон с 6 профессиями
4. **Узнаёте себя?** — Список проблем в стеклянных панелях
5. **Что такое NEIROmaster** — Описание с Always On карточками
6. **Always On** — 3 карточки с иконками (Zap, Code, Rocket)
7. **Программа курса** — Аккордеон с 5 неделями + заключительный урок
8. **Бонусы** — 6 карточек (PromptHub, Промпты, Мастер-классы, Комьюнити, Разборы, Мастермайнды)
9. **Тарифы** — 3 уровня обучения (Самостоятельно, База с куратором, Куратор + Майя)
10. **Специализации** — Закрытые специализации для углубленного обучения
11. **Автор** — Информация о Майе Галицкой
12. **FAQ** — 11 часто задаваемых вопросов

## 🎨 Дизайн-система

### Цвета (LOCKED)

- **Background**: `#0A0A0A` (глубокий чёрный)
- **Primary Neon**: `#3B82F6` (Electric Blue)
- **Secondary Neon**: `#22D3EE` (Cyan)
- **Accent Neon**: `#8B5CF6` (Violet)
- **Text**: `#FFFFFF` / `#B8C0CC`

### Типография

- **Заголовки**: Space Grotesk (68px H1, 46px H2, 30px H3)
- **Текст**: Inter (19px body, line-height 1.6)
- **Mobile**: H1 38px, H2 28px, H3 22px, body 16.5px

### Эффекты

- **Glow**: text-shadow с неоновыми цветами
- **Glass**: rgba(10,10,14,0.55) с blur 18px
- **Blur**: 140-220px для размытых сфер
- **Mix-blend-mode**: screen для наложения

## 🚀 Установка и запуск

```bash
# Установка зависимостей
pnpm install

# Запуск dev-сервера
pnpm dev

# Сборка для production
pnpm build

# Предпросмотр production сборки
pnpm preview
```

## 📱 Адаптивность

- **Mobile**: Оптимизировано для экранов < 640px
- **Tablet**: Адаптивный дизайн для 640px - 1024px
- **Desktop**: Полная функциональность на экранах > 1024px
