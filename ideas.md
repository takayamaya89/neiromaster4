# NEIROMASTER 5.0 — Дизайн-концепция

## Выбранный подход: Технологичный минимализм с AI-акцентами

### Design Movement
**Современный технологичный минимализм** с элементами киберпанка и системного дизайна. Вдохновение: интерфейсы высокотехнологичных компаний (Tesla, Apple, Stripe), где каждый элемент имеет назначение.

### Core Principles
1. **Воздух и пространство** — большие отступы, минимум элементов на экране, дышащий дизайн
2. **Иерархия через типографику** — четкое разделение заголовков, подзаголовков и текста
3. **Световые AI-акценты** — неон-синий/голубой как символ ИИ, контрастирует с темным фоном
4. **Контроль и система** — сетки, выравнивание, предсказуемость в каждом элементе

### Color Philosophy
- **Основной фон**: Очень темный (почти черный) — `oklch(0.08 0 0)` — создает ощущение премиальности и технологичности
- **Текст**: Белый/светло-серый — максимальный контраст, читаемость
- **AI-акцент**: Светящийся голубой — `oklch(0.65 0.2 250)` — символизирует ИИ, используется для CTA, выделения, подсветок
- **Вторичный акцент**: Серебристый/серый — для второстепенных элементов
- **Эмоциональная интенция**: Премиальность, контроль, будущее, профессионализм

### Layout Paradigm
- **Асимметричный дизайн** — не центрированные макеты, а динамичные композиции
- **Вертикальные ритмы** — четкие отступы между блоками (48px, 64px, 80px)
- **Сетка 12 колонок** на десктопе, 1 колонка на мобильном
- **Диагональные элементы** — SVG-разделители, скошенные края для динамики

### Signature Elements
1. **Светящиеся линии и акценты** — тонкие голубые линии, которые подсвечивают ключевые элементы
2. **Абстрактные AI-паттерны** — геометрические фигуры, сетки, которые символизируют нейросети
3. **Монолитные блоки с рамками** — карточки с тонкими светлыми границами на темном фоне

### Interaction Philosophy
- **Плавные переходы** — все элементы движутся мягко (300ms ease-in-out)
- **Hover-эффекты** — легкая подсветка, масштабирование, изменение цвета
- **Микровзаимодействия** — аккордеоны раскрываются плавно, кнопки светятся при наведении
- **Ощущение контроля** — четкие визуальные обратные связи на каждое действие

### Animation
- **Entrance animations** — элементы появляются с fade-in + slight slide-up при скролле
- **Hover states** — кнопки светятся голубым, карточки поднимаются на 4px
- **Scroll-triggered** — блоки анимируются при входе в viewport
- **Micro-interactions** — аккордеоны раскрываются с плавной высотой, иконки вращаются

### Typography System
- **Display font**: `Sora` или `Space Mono` (технологичная, геометричная)
- **Body font**: `Inter` (читаемая, нейтральная)
- **Иерархия**:
  - H1: 48px/56px (мобильный: 32px), bold, Sora
  - H2: 36px/44px (мобильный: 24px), bold, Sora
  - H3: 24px/32px (мобильный: 20px), semibold, Sora
  - Body: 16px/24px, regular, Inter
  - Small: 14px/20px, regular, Inter
  - Caption: 12px/16px, regular, Inter (для мелкого текста)

## Реализация в коде
- Темный фон по умолчанию (dark theme в App.tsx)
- Голубой акцент как primary color
- Большие отступы (gap: 64px, 80px между блоками)
- Минимум элементов на экране
- Все анимации через Framer Motion
- SVG-разделители между блоками для динамики
